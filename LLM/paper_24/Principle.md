Principle 1: Robustness to Verification Noise and Error Propagation in LLM-as-a-Judge Memory Curation

**Definition:**  
In self-evolving agent systems operating without ground-truth supervision, memory curation fundamentally depends on proxy correctness signals typically generated by an LLM-as-a-judge. Because these binary success/failure labels directly determine which trajectories are distilled into reusable reasoning strategies and which counterfactual pitfalls are preserved, any verification noise threatens to compound across the memory bank and corrupt future decision-making. This principle demands rigorous evaluation of whether the memory framework remains robust when self-assessment accuracy degrades from near-perfect to practically noisy levels. It further requires understanding whether the system can gracefully absorb mislabeled trajectories without catastrophic performance collapse, and whether alternative signal pathways—such as self-contrastive aggregation across multiple rollouts—can bypass fragile explicit judgment entirely. Ultimately, a trustworthy memory mechanism must demonstrate that its benefits are not contingent on an unrealistically accurate oracle.

**Core Evaluation Criteria:**
- **Calibration and Noise Injection:** Does the work quantify the baseline accuracy of self-judgment against ground-truth labels and simulate degradation across the full practical range (e.g., 100% down to 50% random-guessing)?
- **Graceful Degradation:** Does performance remain stable within the practical noise range, or does the system exhibit a sharp threshold beyond which memory quality collapses?
- **Alternative Signal Pathways:** Are there mechanisms (e.g., contrastive aggregation from parallel rollouts) that reduce or eliminate dependence on explicit binary self-labels while preserving gains?
- **Error Propagation Analysis:** Does the work analyze how misjudged episodes propagate into specific memory corruption modes (e.g., incorrect strategy extraction, misattributed failure reasons)?

Principle 2: Semantic Distillation Quality and Constructive Utilization of Failed Experience in Structured Memory

**Definition:**  
A core differentiator of advanced agent memory is its ability to abstract raw interaction logs into generalizable, strategy-level knowledge rather than storing inert trajectories or success-only workflows. This principle scrutinizes the semantic quality of distilled memory items, demanding that they capture transferable reasoning patterns rather than spurious, instance-specific correlations. It places special emphasis on the constructive role of failed experiences, evaluating whether negative trajectories are transformed into preventative guardrails or instead degrade behavior through misattributed causes and pathological pattern memorization. The abstraction level must be carefully calibrated: overly specific items fail to transfer, while overly broad items provide no actionable guidance. High-quality research in this space must therefore demonstrate not only aggregate performance gains from failure inclusion, but also safeguards against harmful memory injection and qualitative evidence of meaningful abstraction.

**Core Evaluation Criteria:**
- **Abstraction Level:** Do memory items represent strategy-level reasoning (e.g., "validate state after ambiguous actions") rather than low-level action sequences or raw trajectory snippets?
- **Failure Constructiveness:** Is there controlled evidence that adding failure-derived memories improves performance relative to success-only baselines, without introducing behavioral degradation or overfitting to pathological patterns?
- **Negative Case Analysis:** Does the work systematically examine cases where memory items are flawed—due to misattribution, over-generalization, or over-specificity—and quantify their downstream impact?
- **Redundancy and Noise Control:** Are there mechanisms to prevent accumulation of redundant, contradictory, or harmful entries as the memory bank grows?

Principle 3: Cost-Efficiency and Latency-Scalability Trade-offs in Memory-Augmented Test-Time Inference

**Definition:**  
Memory-augmented agents incur significant inference overhead from auxiliary LLM calls for judgment, extraction, embedding generation, and similarity retrieval, which can erode the practical value of any step-count or success-rate improvements. This principle asserts that evaluation must move beyond coarse efficiency metrics like average interaction steps to rigorously quantify total token consumption, wall-clock latency, and time-to-first-token penalties introduced by the memory module. It further requires evidence that the retrieval and consolidation pipeline can scale to large memory banks—potentially spanning millions of entries in lifelong deployment—without becoming a computational bottleneck. A cost-effective memory system must demonstrate that its overhead grows sub-linearly with bank size and that its per-task resource investment is justified by substantial downstream performance returns. Without such analysis, claimed efficiency gains risk being illusory in production settings where latency and cost dominate deployment decisions.

**Core Evaluation Criteria:**
- **Granular Cost Breakdown:** Does the work report token consumption (input/output) and inference latency disaggregated by stage (action generation, judging, extraction, retrieval)?
- **Step-Latency Trade-off:** Are reductions in interaction steps offset by increased per-step compute or TTFT, and is the net resource cost justified by the performance delta?
- **Bank-Size Scalability:** Does the retrieval mechanism (e.g., vector search libraries, hierarchical pruning) support efficient scaling to thousands or millions of entries, and are latency projections provided?
- **Compute-Performance Justification:** Is the overall cost increase proportionally bounded (e.g., sub-linear overhead) relative to the magnitude of task-success improvement?

Principle 4: Cross-Domain Transferability and Backbone-Independent Generalization of Reasoning Memory

**Definition:**  
For agent memory to constitute a genuine methodological advance rather than a benchmark-specific artifact, it must exhibit robust transfer across distinct task domains, website ecosystems, and underlying model architectures. This principle evaluates whether distilled reasoning strategies generalize beyond the distribution of tasks used to populate the memory bank, such as from web browsing to software engineering or across unrelated websites with divergent layouts and action spaces. It equally demands validation across diverse backbone models, including both frontier closed-source APIs and smaller open-source instruct models, to rule out idiosyncratic prompt-engineering effects tied to a single model family. Strong empirical evidence requires not merely positive mean performance deltas, but also statistical reliability metrics such as variance and confidence intervals across multiple independent runs. Research that lacks cross-domain or cross-model validation risks overfitting to narrow experimental conditions and fails to establish the universal utility of the proposed memory mechanism.

**Core Evaluation Criteria:**
- **Cross-Domain Transfer:** Are experiments conducted across qualitatively distinct environments (e.g., e-commerce, social forums, software engineering) to validate that memory is not merely replaying domain-specific patterns?
- **Model Family and Scale Coverage:** Does the evaluation span multiple model providers and sizes, including smaller open-source models, to demonstrate that gains are architectural hyperparameters rather than model-specific accidents?
- **Statistical Reliability:** Are results reported with variance, standard deviation, or confidence intervals across repeated trials, especially for subset evaluations?
- **Domain-Agnostic Design:** Is the memory schema and extraction methodology sufficiently generic that adaptation to new scenarios requires minimal prompt tuning or manual engineering?

Principle 5: Causal Attribution of Memory Components via Controlled Isolation and Mechanistic Ablation

**Definition:**  
Sophisticated memory frameworks comprise multiple interacting subsystems—extraction, retrieval, consolidation, and aggregation—whose individual contributions must be disentangled to claim scientific progress. This principle insists that empirical comparisons hold constant all variables except the one under study; for example, when claiming superiority of a distillation strategy, retrieval and consolidation mechanisms must be identical across baselines to avoid confounding. It further requires mechanistic transparency in how scaled exploration (e.g., parallel or sequential test-time scaling) synthesizes contrastive signals into memory, rather than treating aggregation as an opaque black box. Reviewers must distinguish between mere output stabilization provided by memory hints and true emergent capability gains where the agent develops qualitatively new reasoning strategies over time. Without such causal attribution and controlled isolation, reported improvements cannot be confidently traced to the advertised innovation.

**Core Evaluation Criteria:**
- **Controlled Component Isolation:** When comparing against baselines, are retrieval and consolidation mechanisms intentionally fixed so that observed differences are strictly attributable to the extraction or aggregation method under test?
- **Mechanistic Transparency:** Is the aggregation process (e.g., self-contrast across parallel rollouts, self-refinement in sequential rollouts) explained in sufficient detail to rule out black-box reasoning?
- **Emergence vs. Stabilization:** Does the work distinguish between using memory to stabilize existing behaviors and genuine emergent improvement where novel, increasingly complex strategies evolve over sequential tasks?
- **Ablation Completeness:** Are key design choices systematically ablated, including memory retrieval quantity, consolidation strategies, and scaling aggregation modes, to isolate their marginal contributions?
