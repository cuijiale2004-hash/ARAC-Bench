Given Topic: The rapid proliferation of large language models has created an urgent need for effective test-time collaboration mechanisms that leverage heterogeneous model capabilities across diverse domains. Existing multi-agent systems predominantly rely on exhaustive activation of all available agents followed by simple concatenation-based aggregation. This paradigm suffers from three fundamental limitations: the inability to selectively activate task-relevant agents from expanding pools, the absence of fine-grained pairwise communication protocols that respect inter-agent relevance, and computationally prohibitive integration schemes that treat all contributions uniformly. Consequently, these approaches face severe scalability bottlenecks as model ecosystems grow, while irrelevant participants introduce noise and dilute domain-specific expertise. The core scientific challenge is establishing a scalable, adaptive collaboration framework that enables selective agent participation, structured relevance-aware communication, and efficient response integration for complex multi-domain reasoning tasks.

Given Inspiration:
1. Graph-theoretic abstractions offer a natural paradigm for representing heterogeneous entities and their relational dependencies in complex systems.
2. In large model ecosystems, task relevance is unevenly distributed across participants, suggesting the necessity of selective activation rather than exhaustive enumeration.
3. Directional and weighted information flow between specialized entities can potentially replace uniform broadcast mechanisms to achieve more efficient consensus building.
4. Hierarchical refinement dynamics, where stronger initial hypotheses guide weaker ones while subsequent improvements feed back to refine the original sources, mirror bidirectional optimization processes.
5. Adaptive compression strategies from geometric deep learning suggest that aggregated intelligence can be distilled without retaining redundant low-level representations.
