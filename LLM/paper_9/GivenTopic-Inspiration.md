Given Topic: Large language model performance is heavily contingent on the alignment between training data composition and downstream evaluation tasks. However, in numerous practical deployment scenarios, the evaluation data remains entirely inaccessible due to privacy constraints or encryption, rendering conventional data curation strategies ineffective. Existing data mixing and selection methodologies predominantly presuppose access to fine-grained evaluation information—such as data distributions, labels, or gradient signals—which is unavailable when only coarse, noisy feedback signals (e.g., aggregate user ratings) can be collected through model deployment. This creates a critical bottleneck: practitioners must optimize training data mixtures for unseen, black-box evaluation tasks using only limited, expensive, and stochastic feedback, without knowledge of the target domain. The core scientific problem lies in developing a principled, sample-efficient framework that can iteratively refine training data compositions under severe information asymmetry, bridging the gap between black-box downstream tasks and trainable data configurations.

Given Inspiration:
1. The iterative model improvement cycles observed in production environments, where systems evolve through sequential rounds of coarse, aggregated feedback without direct access to underlying evaluation data.
2. Surrogate model-based experimental design for expensive black-box optimization, enabling sample-efficient exploration of compositional configuration spaces under noisy, sparse observations.
3. The hierarchical structure of training data design problems, where global allocation across domains and local selection within domains constitute distinct but coupled sub-problems.
4. Operational privacy constraints that render evaluation data invisible to model developers, creating an information asymmetry that demands feedback-driven rather than data-driven optimization.
5. The statistical quantification of individual training instances' intrinsic utility, which can be characterized independently of any specific downstream task to improve subset selection reliability.
