Given Topic: In the field of multimodal large language models, the joint processing of extensive visual and textual sequences incurs substantial computational and memory overhead, particularly as input resolution and sequence length increase. Existing approaches predominantly rely on task-agnostic visual token compression integrated during model construction or perform task-related compression within intermediate layers of the language model under the assumption that shallow-layer visual representations are indispensable. These paradigms either fail to exploit instruction-specific redundancy or constrain deployment flexibility by requiring architectural modifications and full prefilling. The core scientific issue is whether task-related visual token compression can be effectively performed prior to the language model computation without altering the backbone architecture, thereby reducing both prefilling and decoding costs while preserving multimodal reasoning capabilities.

Given Inspiration:
1. Explainability methods developed for transformer architectures offer a theoretically grounded approach to tracing the global contribution of individual input tokens to final outputs, suggesting that post-hoc relevance propagation can reliably quantify task-specific visual token importance.
2. The widespread assumption that shallow-layer visual tokens are indispensable for cross-modal alignment warrants re-examination; evidence indicates that selective retention at the input stage can preserve reasoning capability when guided by proper importance criteria.
3. Compression objectives should be conditioned on user instructions rather than visual input statistics alone, implying that redundancy is fundamentally task-dependent and that optimal token selection must align with the model’s instruction-following objective.
4. Early-layer attention distributions contain sufficient structural information about cross-modal interactions to approximate deeper, computation-intensive explainability signals, motivating the use of lightweight mappings for efficient importance prediction.
5. Biological visual systems demonstrate that task-directed scene perception relies on selective attention to semantically relevant regions rather than uniform processing, supporting the hypothesis that computational multimodal systems can similarly discard task-irrelevant visual information.
