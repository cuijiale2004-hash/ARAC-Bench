Given Topic: Denoising-based generative modeling with transformer architectures has emerged as a dominant paradigm for high-fidelity image synthesis. Recent advances demonstrate that intermediate representation alignment significantly accelerates training convergence and improves output quality. However, prevailing approaches achieve this by relying on large-scale external visual encoders, which creates two fundamental limitations. First, distribution mismatches between the encoder's pre-training corpus and the target generation domain may introduce misleading feature guidance. Second, the substantial computational cost associated with pre-training or domain-specific fine-tuning of such encoders presents a significant scalability barrier. The core scientific problem is to develop a training framework that provides effective semantic representation guidance for denoising-based generative transformers without dependence on external supervised encoders, thereby removing distribution assumptions and reducing computational overhead while preserving training efficiency.

Given Inspiration:
1. Empirical evidence indicates that representation guidance primarily facilitates early-layer semantic feature extraction in generative transformers, allowing deeper layers to specialize in high-frequency detail reconstruction once robust semantic foundations are established.
2. The reliance on external visual encoders for feature supervision functions analogously to supervised learning with fixed labels, which incurs substantial annotation costs and risks inaccurate guidance when source and target domains diverge.
3. Independent noise corruption of an identical underlying image produces multiple distinct noisy observations that nonetheless share invariant semantic content, suggesting that cross-view semantic consistency can serve as an internal self-supervisory mechanism.
4. Transformer-based denoising models exhibit an inherent architectural tension between global low-frequency semantic encoding and local high-frequency detail decoding, implying that semantic conditioning can be isolated and regularized as a decoupled training objective.
5. In unsupervised representation learning, multiple feature instances derived from differently corrupted versions of the same source data should inherently cluster around a common semantic prototype, enabling self-alignment without requiring external reference networks.
