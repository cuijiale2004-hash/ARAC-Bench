**1. Research Background and Existing Pain Points**

Diffusion models achieve state-of-the-art image quality. However, sampling is costly at inference time because it requires a large number of function evaluations (NFEs). To reduce NFEs, classical ODE numerical methods have been adopted. Along one axis, classical ODE methods—singlestep Runge–Kutta and multistep Adams–Bashforth—provide off-the-shelf accuracy–NFE trade-offs. Along a second axis, diffusion-dedicated solvers exploit the structure of the denoising dynamics: they approximate noise or data predictions with low-order Taylor expansions or Lagrange interpolation and derive closed-form updates. Along a third axis, learned solvers optimize the timestep schedule and other sampling-related parameters.

Yet, several pain points exist:
1. **Discretization discrepancy of prediction types:** The choice of prediction type (noise, velocity, or data) and integration domain leads to different sampling behaviors. In continuous time, noise, velocity, and data predictions yield the same update; in discrete time, they do not. They differ at order $O((\Delta \lambda_{t_i})^2)$, raising the question of which update is preferable in practice.
2. **Limitations of learned solvers:** Because parameters depend on the backbone and dataset, such solvers are typically tailored to specific backbones and settings (e.g., a chosen NFE and guidance scale). Training also incurs substantial preparation overhead, as it requires many teacher trajectories or final samples generated using high-NFE sampling.
3. **Limitations of regression-based parameter learning:** Existing regression-based methods (trajectory regression, sample regression, feature regression) compare the trajectories or final samples generated by a student solver and a teacher solver running at high NFE. These methods require a teacher solver and incur substantial overhead in preparing supervision targets, and they tend to perform poorly in the very low NFE regime (e.g., NFE $\le$ 5).

**2. Core Research Motivation and Scientific Questions**

The core research motivation is to address the discretization discrepancy among prediction types, the rigid choice of integration domains, and the substantial overhead and poor low-NFE performance of existing learned solvers. 

The scientific questions are:
- How to generalize multistep samplers through learnable parameters that continuously interpolate among prediction types?
- How to continuously select the integration domain between logarithmic and linear domains?
- How to adjust the residual terms while preserving second-order local accuracy?
- How to learn solver parameters efficiently without relying on high-NFE teacher solvers or target samples?

**3. Overall Core Idea and Design Philosophy**

The overall core idea is to introduce Dual-Solver, a generalized ODE solver for diffusion models with dual prediction. Dual-Solver retains the standard predictor-corrector structure while preserving second-order local accuracy. It introduces three types of learnable parameters:
1. A prediction parameter $\gamma$ that interpolates among noise, velocity, and data predictions.
2. A domain change parameter $\tau$ that interpolates between logarithmic and linear domains.
3. A residual parameter $\kappa$ that adjusts the residual term while preserving second-order accuracy.

The design philosophy further proposes a classification-based learning strategy that yields high-fidelity images even in the low-NFE regime. Unlike regression-based learning, which typically requires many target samples generated at high NFEs, this approach requires no target samples. Solver parameters are learned using either pretrained image classifiers or a zero-shot classifier via a hard-label classification objective.

**4. Core Innovation Points**

1. **Dual Prediction with Parameter $\gamma$:** A dual prediction scheme that uses both $x_\theta$ and $\epsilon_\theta$ together, treating them separately unlike velocity prediction. It introduces an integral formulation parameterized by $\gamma$, which interpolates between the integral forms of noise prediction ($\gamma = -1$), velocity prediction ($\gamma = 0$), and data prediction ($\gamma = 1$). It controls how much $x_{t_i}$ contributes to $x_{t_{i+1}}$.
2. **Log-Linear Domain Change with Parameter $\tau$:** A log-linear transform parameterized by a scalar $\tau$ that continuously interpolates between the linear transform ($\tau \to 0^+$) and the logarithmic transform ($\tau = 1$). It is applied to the integrals in the dual prediction formulation, allowing separate parameters $\tau_u$ and $\tau_v$ for the $u$- and $v$-integrals, ensuring numerical stability near zero.
3. **Approximation with Parameter $\kappa$:** An $O((\Delta u_i)^2)$ term $K(\Delta u_i; \kappa_u) = \kappa_u (\Delta u_i)^2$ introduced to allow additional flexibility in the residual term while preserving local accuracy. The scalar parameter $\kappa_u$ controls the magnitude of the residual term.
4. **Classification-based Parameter Learning:** A hard-label classification objective that compares the student’s classifier outputs (probabilities) against the input class label using a cross-entropy loss, without any teacher solver. This focuses on whether the generated samples lie on the correct side of the classifier’s decision boundary, enabling less restrictive training and removing the dependency on high-NFE teacher targets.

**5. Overview of the Overall Technical Solution**

Dual-Solver performs sampling using a predictor–corrector scheme based on the developed equations. It requires a backbone that provides both $x_\theta$ and $\epsilon_\theta$. The sampling process uses a first-order predictor with a second-order corrector. At step $i$, the first-order predictor takes the current state $x_{t_i}$ and the model evaluations to produce a provisional sample $x'_{t_{i+1}}$. The second-order corrector then combines the evaluations at $t_i$ with fresh evaluations at $t_{i+1}$ to yield the corrected sample $x_{t_{i+1}}$. The learnable parameters for each step include $\phi_i^{\text{pred}} = \{\gamma_i^{\text{pred}}, \tau_{u,i}^{\text{pred}}, \tau_{v,i}^{\text{pred}}, \kappa_{u,i}^{\text{pred}}, \kappa_{v,i}^{\text{pred}}\}$ and $\phi_i^{\text{corr}} = \{\gamma_i^{\text{corr}}, \tau_{u,i}^{\text{corr}}, \tau_{v,i}^{\text{corr}}, \kappa_{u,i}^{\text{corr}}, \kappa_{v,i}^{\text{corr}}\}$, alongside the learned evaluation times. All solver parameters are optimized end-to-end with a hard-label classification objective using a pretrained classifier.

**6. Detailed Module Design**

**6.1 Dual Prediction with Parameter $\gamma$**
We propose a dual prediction scheme that uses both $x_\theta$ and $\epsilon_\theta$ together. We introduce the following integral formulation parameterized by $\gamma$, which interpolates between the integral forms of noise, velocity, and data prediction.
Integral form of dual prediction:
$x_{t_{i+1}} = A x_{t_i} + B \left[ \int_{t_i}^{t_{i+1}} C x_\theta(x_t, t) dt + \int_{t_i}^{t_{i+1}} D \epsilon_\theta(x_t, t) dt \right]$,
where
$\begin{cases} A = (\sigma_{t_{i+1}} / \sigma_{t_i})^\gamma, B = \sigma_{t_{i+1}}^\gamma, C = \frac{d}{dt}(\alpha_t \sigma_t^{-\gamma}), D = \frac{d}{dt}(\sigma_t^{1-\gamma}) & \text{for } \gamma \ge 0, \\ A = (\alpha_{t_{i+1}} / \alpha_{t_i})^{-\gamma}, B = \alpha_{t_{i+1}}^{-\gamma}, C = \frac{d}{dt}(\alpha_t^{1+\gamma}), D = \frac{d}{dt}(\sigma_t \alpha_t^\gamma) & \text{for } \gamma < 0. \end{cases}$
Properties: When $\gamma = -1$, it reduces to noise-prediction; when $\gamma = 0$, velocity-prediction; when $\gamma = 1$, data-prediction. Increasing $\gamma$ decreases the coefficient $A$ multiplying $x_{t_i}$, whereas decreasing $\gamma$ increases $A$. The differential form of dual prediction is:
$\frac{dx_t}{dt} = \beta x_t + \alpha_t \left( \frac{d \log \alpha_t}{dt} - \beta \right) x_\theta(x_t, t) + \sigma_t \left( \frac{d \log \sigma_t}{dt} - \beta \right) \epsilon_\theta(x_t, t)$.

**6.2 Log-Linear Domain Change with Parameter $\tau$**
Let $L : (0,\infty) \to I$ be a $C^1$ diffeomorphism. We define:
$\begin{cases} u(t) = L(\alpha_t \sigma_t^{-\gamma}), v(t) = L(\sigma_t^{1-\gamma}) & \text{for } \gamma \ge 0, \\ u(t) = L(\alpha_t^{1+\gamma}), v(t) = L(\sigma_t \alpha_t^\gamma) & \text{for } \gamma < 0. \end{cases}$
By the chain rule, we obtain:
$x_{t_{i+1}} = A x_{t_i} + B \left[ \int_{u_i}^{u_{i+1}} \frac{dL^{-1}(u)}{du} x_\theta(u) du + \int_{v_i}^{v_{i+1}} \frac{dL^{-1}(v)}{dv} \epsilon_\theta(v) dv \right]$.
We propose a log-linear transform parameterized by a scalar $\tau$:
$L(y; \tau) = \frac{\log(1 + \tau y)}{\tau}, \tau > 0$.
This transform is invertible, with inverse $L^{-1}(u; \tau) = (e^{\tau u} - 1)/\tau$; its weighting factor is $\frac{d}{du}L^{-1}(u; \tau) = e^{\tau u}$.
Properties: As $\tau \to 0^+$: $L(y; \tau) \to y, \frac{d}{du}L^{-1}(u; \tau) \to 1$. When $\tau = 1$: $L(y; \tau) = \log(1 + y), \frac{d}{du}L^{-1}(u; \tau) = e^u$. We apply it with separate parameters $\tau_u$ and $\tau_v$.

**6.3 Approximation with Parameter $\kappa$**
On the interval $[u_i, u_{i+1}]$, we approximate $x_\theta$ in two ways: (i) the first-order approximation $x_\theta(u) = x_\theta(u_i)$; and (ii) the second-order forward-difference approximation $x_\theta(u) = x_\theta(u_i) + \frac{\Delta x_\theta(u_i)}{\Delta u_i}(u - u_i)$. We introduce $K(\Delta u_i; \kappa_u) = \kappa_u (\Delta u_i)^2$, an $O((\Delta u_i)^2)$ term, to allow additional flexibility in the residual term while preserving local accuracy.
First-order predictor $x_{t_{i+1}}^{\text{1st-pred.}}$:
$x_{t_{i+1}}^{\text{1st-pred.}} = A x_{t_i} + B \left[ x_\theta(u_i) \left( \Delta L^{-1}(u_i) + K(\Delta u_i; \kappa_u) \right) + \epsilon_\theta(v_i) \left( \Delta L^{-1}(v_i) + K(\Delta v_i; \kappa_v) \right) \right]$.
Second-order corrector $x_{t_{i+1}}^{\text{2nd-corr.}}$:
$x_{t_{i+1}}^{\text{2nd-corr.}} = A x_{t_i} + B \left[ x_\theta(u_i) \Delta L^{-1}(u_i) + \frac{\Delta x_\theta(u_i)}{2} \left( \Delta L^{-1}(u_i) + K(\Delta u_i; \kappa_u) \right) + \epsilon_\theta(v_i) \Delta L^{-1}(v_i) + \frac{\Delta \epsilon_\theta(v_i)}{2} \left( \Delta L^{-1}(v_i) + K(\Delta v_i; \kappa_v) \right) \right]$.
Second-order predictor $x_{t_{i+1}}^{\text{2nd-pred.}}$:
$x_{t_{i+1}}^{\text{2nd-pred.}} = A x_{t_i} + B \left[ x_\theta(u_i) \Delta L^{-1}(u_i) + \frac{\Delta x_\theta(u_{i-1})}{2 r_i^{(u)}} \left( \Delta L^{-1}(u_i) + K(\Delta u_i; \kappa_u) \right) + \epsilon_\theta(v_i) \Delta L^{-1}(v_i) + \frac{\Delta \epsilon_\theta(v_{i-1})}{2 r_i^{(v)}} \left( \Delta L^{-1}(v_i) + K(\Delta v_i; \kappa_v) \right) \right]$
where $r_i^{(u)} := \Delta u_{i-1} / \Delta u_i$ and $r_i^{(v)} := \Delta v_{i-1} / \Delta v_i$.

**6.4 Parameter Learning Module**
Hard-label classification compares the student’s classifier outputs against the input class label using a cross-entropy loss, without any teacher solver. The sample $x_0$ generated by the solver $S$ is passed through the decoder $D$ and the classifier $C$ to obtain class probabilities $p$. We compute a cross-entropy loss between $p$ and the class label $y \sim Y$, and update solver parameters $\phi$ for all time steps via backpropagation. For text-to-image tasks, the class labels are replaced with text prompts, and the cross-entropy loss is replaced with CLIP loss.

**8. Algorithm Pseudocode**

**Algorithm 1** Dual-Solver predictor–corrector sampling (Sec. 4.1)
Require: Diffusion backbone with dual prediction $\{x_\theta, \epsilon_\theta\}$, timesteps $\{t_i\}_{i=0}^M$, initial noise $x_{t_0}$, empty list $\ell$, parameters $\phi$
1: Evaluate $\{x_\theta(x_{t_0}, t_0), \epsilon_\theta(x_{t_0}, t_0)\}$ and add to $\ell$
2: for $i = 0$ to $M - 1$ do
3: $x'_{t_{i+1}} \leftarrow \text{Predictor}(x_{t_i}, \ell; \phi_i^{\text{pred}})$
4: if $i == M - 1$ then break
5: Evaluate $\{x_\theta(x'_{t_{i+1}}, t_{i+1}), \epsilon_\theta(x'_{t_{i+1}}, t_{i+1})\}$ and add to $\ell$
6: $x_{t_{i+1}} \leftarrow \text{Corrector}(x_{t_i}, \ell; \phi_i^{\text{corr}})$
7: end for
8: return $x'_{t_M}$

**Algorithm 2** Hard-label classification for parameter learning (Sec. 5.2)
Require: Diffusion backbone with parameters $\theta$, VAE decoder $D$, pretrained classifier $C$, solver $S$ with parameters $\phi$, label dataset $Y$, learning rate $\eta$
1: while not converged do
2: Sample $x_T \sim \mathcal{N}(0, I)$ \hfill $\triangleright$ initial noise
3: Sample $y \sim Y$ \hfill $\triangleright$ class label
4: $x_0 \leftarrow S(x_T; y, \phi, \theta)$ \hfill $\triangleright$ sampling
5: $\hat{x}_0 \leftarrow D(x_0)$ \hfill $\triangleright$ decoding
6: $p \leftarrow C(\hat{x}_0)$ \hfill $\triangleright$ class probabilities
7: $\mathcal{L} \leftarrow \text{CrossEntropy}(p, y)$ \hfill $\triangleright$ loss
8: $\phi \leftarrow \phi - \eta \nabla_\phi \mathcal{L}$ \hfill $\triangleright$ parameter update
9: end while
