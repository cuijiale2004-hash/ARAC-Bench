Given Topic: This study addresses the enhancement of large language models with dynamically retrieved external knowledge in iterative reasoning scenarios. Current retrieval-augmented paradigms rely on injecting retrieved documents into the input context, leading to inefficiency, susceptibility to noise, and conflicts with parametric knowledge. Although recent parametric adaptation methods internalize retrieved information directly into model weights, they are restricted to single-step retrieval and cannot support multi-hop reasoning chains. The central problem is how to progressively accumulate sequentially retrieved knowledge into model parameters across multiple reasoning hops while mitigating interference between successive updates, without requiring architectural retraining or redesign for each retrieval step.

Given Inspiration:
1. **Deficiency of single-pass parametric retrieval**: Existing parameter-level augmentation methods only support one-step retrieval, whereas complex reasoning inherently demands iterative evidence gathering across multiple hops.
2. **Catastrophic interference in sequential updating**: Continuously incorporating new retrieved knowledge into model parameters risks overwriting previously integrated information, motivating a need to preserve complementary, non-redundant representations across reasoning stages.
3. **Orthogonal subspace projection**: Principles from linear algebra suggest decomposing sequential knowledge updates into overlapping and orthogonal components, so that each new addition only contributes information not already captured by prior accumulations.
4. **Localized knowledge representation in deep networks**: Empirical evidence that factual associations are concentrated in specific early-to-middle layers suggests external knowledge can be efficiently encoded by targeting narrow, task-critical subspaces rather than full-network adaptation.
5. **Meta-learning for rapid knowledge translation**: The need to convert unstructured retrieved documents into model-compatible parametric updates without costly fine-tuning motivates employing auxiliary networks that generate task-specific parameters on demand.
6. **Discrete memory mechanisms**: Augmenting networks with compact, individually addressable memory slots draws inspiration from neural memory architectures that store and retrieve distinct knowledge units through content-based access.
