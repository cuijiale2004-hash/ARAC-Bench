Given Topic: Federated learning enables collaborative model training across decentralized data while preserving privacy. Conventional approaches predominantly rely on gradient-based optimization, which intrinsically suffers from severe performance degradation under non-IID data distributions, poor scalability to large-scale client populations, unstable convergence, and substantial communication and computation overhead. Although recent gradient-free analytic learning methods circumvent these issues by deriving closed-form solutions via least squares, they are constrained to shallow single-layer linear mappings built upon frozen pre-trained feature extractors. This restriction inherently eliminates adaptive representation learning within the federated system, resulting in limited model capacity and suboptimal feature separability. The core scientific problem is therefore how to enable deep hierarchical representation learning in distributed analytic learning without resorting to gradient-based backpropagation, while preserving the closed-form tractability and strict invariance to data heterogeneity that define the analytic paradigm.

Given Inspiration:
1. Deep identity-mapping bypass pathways in iterative learning systems suggest that analogous structural mechanisms may enable progressive feature refinement in non-gradient frameworks.
2. The analytic least-squares paradigm for shallow distributed classification indicates that closed-form tractability could theoretically extend to hierarchical models if depth is introduced without breaking convex solvability.
3. Empirical observations that depth constructed via fixed stochastic feature expansions coupled with nonlinearities yields diminishing returns imply that a learnable corrective term is necessary for progressive representation enhancement.
4. Mathematical structures in bilinear matrix equations reveal that unknown transformations interposed between feature and classifier spaces admit analytical resolution via decomposition principles, bypassing iterative gradient updates.
5. The capacity limitation inherent in freezing backbone representations and restricting adaptation to a solitary linear mapping underscores the necessity of embedding trainable hierarchical feature adaptation within gradient-free distributed protocols.
