Given Topic: Knowledge graph question answering via large language models faces fundamental limitations in handling complex multi-hop and logically compositional queries. Existing approaches predominantly rely on linear entity-relation path expansion with intermediate candidate pruning, which prematurely eliminates correct answers and restricts reasoning to simple sequential patterns. Furthermore, prevailing retrieve-and-answer paradigms induce excessive dependence on retrieved subgraph evidence, causing error propagation when spurious or weakly related entities are encountered. The core challenge lies in designing a reasoning framework that preserves candidate diversity during structured exploration while reconciling conflicts between parametric knowledge and external graph evidence, ultimately enabling robust handling of conjunctions, compositions, and comparative constraints.

Given Inspiration:
1. Linear graph traversal with aggressive pruning inherently truncates search spaces and eliminates valid candidates, suggesting that complex reasoning requires logically decomposed objectives rather than monolithic sequential paths.
2. Formal graph query languages encode compositional logic through nested constraints and set operations, indicating that natural language questions can be aligned with structurally decomposed sub-goals.
3. Human cognitive processes often form preliminary hypotheses before external verification, motivating an iterative paradigm where internal knowledge provides tentative answers subsequently corrected by evidence.
4. The tension between parametric knowledge and retrieved external facts frequently produces inconsistencies, inspiring an explicit mechanism that adjudicates conflicts rather than unconditionally accepting retrieved evidence.
5. Complex constraints involving multiple intersecting conditions exceed the expressive capacity of single-branch path walking, pointing toward planning mechanisms that support parallel constraint evaluation and set intersection.
