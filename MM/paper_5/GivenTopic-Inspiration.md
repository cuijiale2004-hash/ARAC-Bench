Given Topic: Multimodal large language models currently perform reasoning predominantly within the textual modality, treating visual inputs as static preconditions or relying on external tools to manipulate visual signals during intermediate reasoning steps. These paradigms suffer from inherent limitations: textual chain-of-thought reasoning provides only an indirect representation of visual understanding and may suppress critical visual cues, while tool-based visual editing is constrained by predefined operations, limited extensibility, and training inefficiency. Furthermore, persistent challenges including modality projection bias, cross-modality interference, and attention misalignment prevent models from effectively grounding textual reasoning in fine-grained visual details. The core scientific issue is how to unify multimodal reasoning by enabling the joint processing of visual and textual semantics within a shared latent space, thereby overcoming the fundamental gap between static visual perception and dynamic language generation without dependence on external utilities.

Given Inspiration:
1. The shared embedding hypothesis: if visual and textual tokens reside in a joint semantic space, reasoning operations should naturally encompass both modalities rather than segregating visual perception from textual inference.
2. Human visual cognition: humans can reason about visual content directly without mandatory translation into linguistic descriptions, suggesting that multimodal systems should support non-verbal, visual-centric thought processes.
3. Latent-space expressiveness: continuous hidden states in language models can encode complex semantic information more efficiently than discrete token sequences, motivating the extension of such continuous reasoning into the visual domain.
4. Limitations of tool-augmented paradigms: reliance on external visual editing tools introduces operational brittleness and scalability bottlenecks, inspiring the internalization of visual reasoning capabilities within the model itself.
5. Endogenous alignment: the hypothesis that a unified semantic space can natively reconcile visual and textual representations without requiring auxiliary projection mechanisms or post-hoc feature reinjection.
