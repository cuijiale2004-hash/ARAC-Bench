Given Topic: In the field of multimodal large language models, fine-grained visual perception is essential yet challenging due to the prohibitive computational cost of processing high-resolution imagery in its entirety. Existing region-of-interest paradigms present a difficult trade-off: training-dependent approaches require costly large-scale annotations, while training-free methods that exploit intrinsic model attention suffer from substantial computational overhead during inference and degraded localization accuracy owing to noisy activation maps. The core scientific issue is how to achieve accurate and computationally efficient salient-region identification without dependence on external annotations or multi-pass auto-regressive decoding, thereby enabling scalable high-resolution perception.

Given Inspiration:
1. The intrinsic cross-modal attention within multimodal language models encodes meaningful but noisy spatial localization signals, which can be refined rather than used in raw form.
2. Intermediate network layers represent an optimal stage for extracting visual grounding cues, where cross-modal representations are sufficiently fused but not yet specialized for abstract text generation.
3. Self-generated responses produce attention distributions that are inherently consistent with a model’s own visual grounding mechanism, offering a naturally aligned supervision source compared to external teachers.
4. Noisy continuous attention maps can be converted into sparse, high-confidence discrete supervisory signals by suppressing semantically irrelevant high-norm tokens and ignoring ambiguous middle-range activations.
5. Decoupling region identification from the auto-regressive generation process enables single-pass localization, avoiding the latency associated with sequential decoding or repeated prefilling operations.
6. Leveraging intermediate features already computed during standard forward passes allows efficient region prediction without redundant encoding, outperforming external standalone grounding modules in both speed and contextual relevance.
