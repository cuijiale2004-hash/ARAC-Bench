**1. Research Background and Existing Pain Points**

**Research Background:** 
Existing Multimodal Large Language Models (MLLMs) process a large number of visual tokens, leading to significant computational costs and inefficiency. A common paradigm among existing MLLMs is to jointly feed visual tokens (generated by a vision encoder) and textual tokens into the LLM for cross-modal alignment and integration. This paradigm introduces substantial memory and computational overhead due to the high volume of visual tokens, which grows rapidly with higher resolutions or frame rates. Consequently, there is a pressing need for effective token compression techniques.

**Existing Pain Points:**
1. **Limitations of Task-Agnostic Compression:** Previous exploration of visual token compression methods includes task/instruction-agnostic compression, which aims to obtain more compact and fewer visual representations independent of the LLM. However, visual representations are an integral part of MLLMs and serve as the foundation for achieving strong performance and generalization. Many state-of-the-art MLLMs already incorporate built-in, task-agnostic compression mechanisms (e.g., spatial and temporal pooling) instead of relying on separate compression techniques applied afterward. Applying another round of task-agnostic compression is redundant and has limited potential for efficiency gains.
2. **Inefficient Compression Location of Task-Related Methods:** The second category focuses on selecting visual tokens that are most relevant to the given instruction. Pioneering works like FastV assume that visual tokens achieve better vision–language alignment in the shallow layers of LLMs, leading to task-related token compression being primarily applied in intermediate LLM layers. This assumption limits compression to occur only after tokens have been processed by shallow layers, failing to significantly reduce computational and memory overhead during the initial prefilling phase.
3. **Questionable Assumptions on Shallow Layers:** Previous works generally assume that all visual tokens in the shallow layers of LLM are indispensable for task-related compression. Whether this assumption holds true, or whether an effective task-related token compression approach prior to the LLM exists but remains undiscovered, remains an open and questionable issue.
4. **Lack of Generalization:** Many existing methods are motivated by observations derived from specific network architectures (e.g., LLaVA), which limits their generality and transferability to other MLLM architectures.

**2. Core Research Motivation and Scientific Questions**

**Core Research Motivation:** 
Instruction-related visual token compression demonstrates strong task relevance, which aligns well with MLLMs’ ultimate goal of instruction following. The motivation is to explore the feasibility of an effective task-related token compression approach prior to the LLM (at the input stage) that is model-agnostic, significantly reduces task-irrelevant visual tokens, and enables application without modifying the LLM architecture, thereby achieving faster inference with reductions in both prefilling time and KV-cache memory.

**Scientific Questions:** 
1. Can an effective task-related token compression approach prior to the LLM exist, or is it inherently infeasible? 
2. Are all visual tokens in the shallow layers of LLM truly indispensable for task-related compression? 
3. Can explainability methods for transformer-based architectures evaluate the global importance of each visual token with respect to the given instruction, and can this effectively guide the task-related token compression for MLLMs? 
4. Can a lightweight mapping be learned from the attention map of the first LLM layer to the explanation results to avoid the need for a full inference pass?

**3. Overall Core Idea and Design Philosophy**

The overall core idea is to perform task-related visual token compression at the LLM input stage by leveraging explainability methods to assess visual token importance. The design philosophy posits that explainability methods for transformer-based architectures can evaluate the global importance of each visual token with respect to the given instruction, which can effectively guide the task-related token compression for MLLMs. By revealing that with proper selection, task-related token compression is feasible at the input stage of LLM with negligible performance loss, a new paradigm is established. This paradigm significantly reduces task-irrelevant visual tokens and its model-agnostic design enables application without modifying the LLM architecture. Furthermore, to enable efficient and practical deployment, a mapping is proposed to be learned from the attention map of the first LLM layer to the explanation results using a simple and lightweight convolutional network, whose training is efficient and independent of MLLMs, thereby avoiding the need for a full inference pass.

**4. Core Innovation Points**

1. **Revealing Explainability for Token Compression:** The work reveals that explainability methods can well evaluate the importance of visual tokens, enabling effective token compression at the LLM input stage. This challenges the prevailing assumption that shallow-layer tokens must be fully retained, demonstrating that with proper selection, pruning tokens not relevant to the task at the LLM input stage is indeed feasible.
2. **Highly Efficient Pre-LLM Compressor Learning:** The work proposes a highly efficient token compressor by learning from explanation results. It allows token compression to be performed before the LLM, significantly reducing inference costs at both the prefill and decode phases without requiring any modifications to the prefill and decode phases during inference.
3. **Model-Agnostic Design and Broad Applicability:** Unlike previous works motivated by observations derived from specific network architectures, the explainability-based approach is broadly applicable. It leverages the inherent characteristics of the applied model rather than relying on the behaviors of specific models, demonstrating strong generalization across various architectures (Qwen2-VL, LLaVA-OneVision, and VILA1.5).
4. **Lightweight Attention-to-Relevance Mapping:** The work discovers and leverages the fact that a simple convolutional network applied to the first-layer attention suffices to approximate the full explainability relevance map. This guarantees the compressor’s efficiency in terms of model size, training time, and computation, enabling practical deployment with negligible extra computational cost.

**5. Overview of the Overall Technical Solution**

The overall technical solution consists of two main phases: Explainability-based Token Compression and Explainability-based Compressor Learning. 
In the first phase, to reduce task-related redundancy at the token level, the contribution of each visual token to the model response is estimated using a generic explainability method (Generic Attention Explainability, GAE). This method generates a relevance map by integrating attention weights and corresponding gradients across layers, tracing the semantic relevance flow from generated tokens to raw visual inputs. The resulting relevance map highlights the contributions, enabling the ranking and pruning of less important visual tokens for compression.
In the second phase, to address the limitation that the relevance map is derived post-hoc, a standalone module is proposed to approximate the relevance map. A simple fully convolutional network is trained to predict relevance based on the first-layer attention map of the LLM. Specifically, the attention scores that visual tokens receive from textual instruction tokens in the first layer are extracted, averaged across the textual dimension, and fed into a 1D convolutional model. The training process uses KL divergence against processed relevance labels and is highly efficient, independent of the MLLM. During inference, the learned compressor is applied at the LLM input stage to generate predicted relevance, which guides the token compression before the prefill phase.

**6. Detailed Module Design**

**Module 1: Relevance Maps by Explainability Method**
This module adopts a generic explainability method similar to R-GAE to compute the relevance of the response-to-vision. For each generated textual token $y_t$ at the $t$-th generation step, the relevance map $R_t$ is first initialized as an identity matrix and then iteratively updated across layers. The update is performed from the 0-th layer to the last layer. In the end, the relevance of $y_t$ to visual signals can be extracted by indexing the corresponding positions in the last row of $R_t$, that is, $R_t[-1, N_s : N_s + N_v]$. Finally, the overall visual relevance scores $R_v \in \mathbb{R}^{1 \times N_v}$ with respect to the current response are obtained by aggregating visual relevance across all time steps $t$ by averaging. The relevance propagation computes the Hadamard product of the attention map and its gradient. The intuition is: 1) it captures how much attention each token receives from other tokens; 2) it identifies which tokens require more attention to effectively influence the output. By zeroing out negative gradient components using the $(\cdot)_+$ operation, it enforces a causal direction of influence and prevents the suppression of informative positive signals. Since the attention module is followed by a residual connection, the relevance map is accumulated by adding each layer’s contribution to the aggregated relevance map.

**Module 2: Visual Token Compression Using Relevance Scores**
The importance of visual tokens related to the instruction can be ranked according to the overall visual relevance scores $R_v$. The method prunes the less important visual tokens down to a target count of $\hat{N}_v$, resulting in compressed token embeddings $\hat{E}_v$ as LLM input. This validates that retaining only the corresponding visual tokens based on $R_v$ does not compromise model performance.

**Module 3: Explainability-Based Compressor Learning ($f_\theta$)**
*   **Input Processing:** Let $A^0$ be the first-layer attention map. The submap $A^0_{u \to v} \in \mathbb{R}^{N_u \times N_v}$ is extracted by indexing the attention scores that visual tokens receive from textual instruction tokens. The $N_u$ scores for each visual token are averaged to obtain a compact representation $A^0_v \in \mathbb{R}^{1 \times N_v}$.
*   **Network Architecture:** The averaged attention vector $A^0_v$ is fed into a 1D convolutional model $f_\theta$ to predict visual relevance. $f_\theta$ is implemented as a five-layer fully convolutional network with channel dimensions of 32, 64, 128, 256, and 512. Each layer employs a 1D depthwise separable convolution, i.e., a depthwise convolution with a kernel size of 3 followed by a pointwise convolution. An additional pointwise convolution layer is applied at the end for channel aggregation. A softmax operation is applied at the end of $f_\theta$.
*   **Training Labels:** The ground truth $R_v$ is processed into the training label $R_v^*$ by masking the bottom 50% values and normalizing the remainder into a probability distribution. Instead of softmax—which yields near-uniform values due to the closeness of raw scores—normalization is performed by dividing each score by the total, thereby preserving relative differences.
*   **Training Objective:** The Kullback–Leibler (KL) divergence is used to measure the difference between $R_v^*$ and the predicted $\tilde{R}_v$.
*   **Training Details:** The network is trained using Adam with a batch size of 128. Training data is collected from general-domain high-quality datasets (subset of LLaVA-Video for videos and Infinity-MM for images, ~10K samples). Samples with incorrect answers generated by the MLLM are filtered out. The training is performed for roughly 100 epochs.
*   **Ablation Insights:** Ablation studies show that the 5-layer architecture strikes the optimal balance between model capacity and task complexity. Deeper networks (7 or 10 layers) lead to slight performance degradation due to overfitting. Using the first-layer attention map as input achieves nearly the same performance as multi-layer variants while being significantly more efficient. Gradient-weighted aggregation to generate $R_v$ performs consistently better than simple averaging across attention heads.

**7. All Mathematical Formulas and Symbol Definitions**

**Formulas:**
1. Relevance map iterative update:
   $R_t = R_t + \mathbb{E}_h((A^l_t \odot \nabla A^l_t)_+) \cdot R_t$
2. Relevance map generation for each layer:
   $\bar{A}^l = \mathbb{E}_h((A^l \odot \nabla A^l)_+)$
3. Relevance accumulation with residual connection:
   $R = R + \bar{A}^l \cdot R$
4. Compressor prediction:
   $\tilde{R}_v = f_\theta(A^0_v)$
5. Loss function:
   $L_{KL} = KL(R_v^* || \tilde{R}_v)$
6. FLOPs for a Transformer layer:
   $FLOPs_{layer} = 4nd^2 + 2n^2d + lnm$
7. FLOPs introduced by the first-layer attention map:
   $FLOPs_{attn} = nd^2 + nd$
8. FLOPs introduced by the 1D depthwise separable convolution:
   $FLOPs_{conv} = \sum_{l=1}^L n(C^l_{in}k + C^l_{in}C^l_{out})$

**Symbol Definitions:**
*   $V$: Video or image.
*   $VM$: Vision encoder (and cross-modal projector).
*   $LM$: Language model.
*   $E_v \in \mathbb{R}^{N_v \times C}$: Visual token embeddings.
*   $N_v$: Number of visual tokens.
*   $C$: Feature dimension.
*   $E_s \in \mathbb{R}^{N_s \times C}$: Token embeddings of the system prompt.
*   $E_u \in \mathbb{R}^{N_u \times C}$: Token embeddings of the user instruction.
*   $Y = \{y_0, y_1, \ldots, y_{T-1}\}$: Generated sequence of textual tokens.
*   $A^l_t$: Multi-head attention map in the $l$-th layer at the $t$-th generation step.
*   $\nabla A^l_t$: Gradients corresponding to $A^l_t$.
*   $\odot$: Hadamard product.
*   $\mathbb{E}_h$: Mean across the heads dimension.
*   $(\cdot)_+$: Operation of setting negative values to 0.
*   $R_t$: Relevance map at the $t$-th generation step.
*   $R_v \in \mathbb{R}^{1 \times N_v}$: Overall visual relevance scores.
*   $\hat{N}_v$: Target count of visual tokens after compression.
*   $\hat{E}_v$: Compressed token embeddings.
*   $Comp$: Compression module.
*   $A^0$: First-layer attention map.
*   $A^0_{u \to v} \in \mathbb{R}^{N_u \times N_v}$: First-layer attention submap from textual instruction tokens to visual tokens.
*   $A^0_v \in \mathbb{R}^{1 \times N_v}$: Averaged first-layer attention vector.
*   $f_\theta$: 1D convolutional model (compressor).
*   $\tilde{R}_v$: Predicted visual relevance probability distribution.
*   $R_v^*$: Training label processed from $R_v$.
*   $n$: Number of visual tokens.
*   $d$: Hidden state size.
*   $m$: Intermediate size of the FFN.
*   $l$: Number of layers in the FFN.
*   $N_L$: Number of Transformer layers.
*   $L$: Number of convolutional layers.
*   $k$: Kernel size of convolution.
*   $C^l_{in}$: Number of input channels of the $l$-th convolutional layer.
*   $C^l_{out}$: Number of output channels of the $l$-th convolutional layer.
