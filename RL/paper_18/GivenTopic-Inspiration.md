Given Topic: Offline goal-conditioned reinforcement learning faces substantial challenges in long-horizon reasoning and behavior composition from fixed datasets. Existing paradigms predominantly rely on either local temporal-difference updates, which accumulate errors over extended horizons, or global Monte-Carlo estimation, which propagates values across trajectories but lacks optimality guarantees. This dichotomy results in limited stitching capabilities and poor generalization to tasks longer than those observed during training. Furthermore, scaling these methods to high-dimensional visual observations and real-world robotic manipulation remains difficult due to instability and representational limitations. The core problem is to develop a principled framework that reconciles local consistency with global value propagation to enable scalable, robust goal-reaching and compositional generalization in offline settings.

Given Inspiration:
1. Human cognition leverages inherent distance concepts to measure task progress and plan shortest routes, suggesting that goal-conditioned decision-making can benefit from explicit geometric structure in temporal distance representation.
2. The complementary theoretical properties of local dynamic programming and global Monte-Carlo evaluation indicate that integrating both paradigms may overcome the individual limitations of compounding errors and suboptimal distance recovery.
3. The optimal substructure property inherent in sequential decision tasks implies that intermediate waypoints along trajectories can serve as auxiliary targets for value propagation without requiring hierarchical decomposition.
4. Geometric constraints from distance metric theory, particularly those enforcing directed triangular relationships between states, provide an inductive bias for composing local segments into globally consistent goal-reaching behaviors.
5. The observation that optimal critics should exhibit invariance to action selection at a given state motivates enforcing consistency between state values and state-action values to stabilize long-horizon value estimation.
