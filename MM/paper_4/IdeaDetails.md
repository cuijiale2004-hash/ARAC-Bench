### 1. Research Background and Existing Pain Points

**Research Background:** Reasoning segmentation is a task that generates pixel-level binary masks by interpreting textual queries through logical reasoning. Unlike traditional semantic or instance segmentation, which depends on predefined categorical labels, reasoning segmentation is designed to handle complex, context-dependent queries. This setting reflects real-world needs for intelligent assistants and robots, requiring advanced capabilities such as nuanced textual understanding and logical reasoning, fine-grained visual perception and image–text alignment, and broad domain knowledge combined with common sense. Multi-modal large language models (MLLMs), owing to their integrated reasoning and multi-modal perception abilities, have become a central component in the latest paradigms for this task. Recent studies have investigated two primary MLLM-based paradigms: (1) Supervised Fine-Tuning (SFT), where MLLMs generate special tokens controlling a learnable segmentation head; and (2) Reinforcement Learning (RL), where MLLMs are optimized with reward signals for generating boxes and/or points fed into the Segment Anything Model (SAM).

**Existing Pain Points:**
1. **Limitations of SFT-based methods:** While SFT-based methods effectively incorporate the reasoning capability of MLLMs into segmentation pipelines, they suffer from two key limitations: (i) catastrophic forgetting of general reasoning abilities, and (ii) poor generalization to out-of-domain data.
2. **Limitations of existing RL-based methods:** RL-based methods either decouple MLLMs from SAM during training, leading to sub-optimal segmentation inputs, or fail to fully exploit SAM’s capacity for iterative refinement and interactive segmentation as human users do.
3. **Limitations of SegAgent:** SegAgent is the first approach that emulates the behavior of human SAM users, performing SAM-friendly point generation and iterative mask refinement through RL-style optimization. However, it depends on bounding boxes generated by another MLLM as the initial input for SAM and lacks the ability to adaptively terminate the refinement process as humans do. Moreover, the reliance on hand-crafted ground truth for point traces may constrain its exploration of more effective strategies for mask refinement.
4. **Underutilization of SAM:** Current paradigms fall short in exploiting SAM’s strengths, especially the ability to support iterative mask refinement by interactive segmentation, a process that human users can naturally perform.

### 2. Core Research Motivation and Scientific Questions

**Core Research Motivation:** To bridge the gap between current MLLM-based segmentation paradigms and human-like usage of SAM. Humans naturally perform iterative mask refinement when using SAM. Current methods either lack this iterative refinement capability or cannot adaptively terminate the process. There is a strong need for an experienced mask-aware SAM agent capable of emulating human interaction with SAM via a reasoning-driven segmentation workflow.

**Scientific Questions:** How to empower an MLLM to mimic human behavior when using SAM for reasoning segmentation? Specifically, how to design a framework that enables a single MLLM to unify textual grounding (generating bounding boxes), iterative mask refinement (proposing refinement points based on SAM-generated masks), and adaptive termination within a single reasoning-driven segmentation workflow?

### 3. Overall Core Idea and Design Philosophy

**Overall Core Idea:** Introduce SAM-Veteran, an experienced mask-aware SAM agent capable of emulating human interaction with SAM via a reasoning-driven segmentation workflow. SAM-Veteran follows a complete reasoning-driven segmentation workflow that includes: (1) generating bounding boxes given image–query pairs for SAM input, (2) proposing refinement points based on SAM-generated masks, and (3) adaptively terminating the process.

**Design Philosophy:** To enable the MLLM to perform this human-like workflow, a multi-task reinforcement learning framework based on Group Relative Policy Optimization (GRPO) is proposed, designed to enhance its capabilities in textual grounding and mask comprehension. The framework consists of: (i) a textual grounding task, where the model learns to generate bounding boxes that maximize both box IoU and mask IoU of SAM-predicted masks; (ii) a mask comprehension task, where the model judges whether the SAM-predicted mask is satisfactory and, if not, generates refinement points to effectively improve mask IoU; and (iii) an auxiliary task, which further strengthens mask comprehension by requiring the model to identify the centers of flaws in manually corrupted masks with random false positives and/or false negatives. Furthermore, to stabilize GRPO-based reinforcement learning, the concept of dynamic sampling from DAPO is incorporated into the framework.

### 4. Core Innovation Points

1. **Unified Human-like SAM Agent:** The proposal of SAM-Veteran, an experienced SAM agent that emulates human usage behavior through a reasoning-driven segmentation workflow encompassing box generation, iterative mask refinement, and adaptive termination. It is the first model to unify all of these behaviors within a single framework.
2. **Multi-task Reinforcement Learning Framework:** A multi-task RL framework consisting of three tasks: a grounding task, which trains the model to generate bounding boxes well-suited for SAM segmentation; a mask comprehension task, which enables the model to evaluate mask quality and provide refinement points when necessary; and an auxiliary task, which further enhances the model’s mask comprehension ability via intentionally corrupted masks.
3. **Dynamic Sampling Strategy:** The incorporation and extension of dynamic sampling from DAPO to stabilize GRPO-based reinforcement learning. For the grounding task, dynamic sampling over-samples candidate boxes and applies Non-Maximum Suppression (NMS) to remove duplicates. For mask comprehension tasks, it over-samples actions until all four cases ((null,null), (p+,null), (null, p−), and (p+, p−)) are represented, ensuring diverse actions with varying rewards.
4. **Comprehensive Reward Design for Mask Refinement:** The design of specific reward functions including Decision Reward (RDCS) and IoU Improvement Reward (R∆) to guide the MLLM to terminate the refinement process at the appropriate time and to evaluate how much the IoU is improved by the current action if the mask needs refinement.

### 5. Overview of the Overall Technical Solution

The overall technical solution models the SAM-Veteran workflow as a Markov Decision Process (MDP) (S,A, T,R). The optimized MLLM is treated as an experienced SAM user, which carries out textual grounding, iterative mask refinement, and adaptive termination. Given an image I and a question Q, the MLLM is prompted to generate a bounding box b, which SAM uses to produce an initial mask M. The image and resulting mask are fed back into the MLLM, which generates refinement points (p+, p−) for SAM to update the mask M′. This continues until the MLLM determines the mask is satisfactory (outputs null for both points) or the maximum step is reached. To learn the policy πθ(a|s), a multi-task RL framework based on GRPO is proposed, comprising Task 1: Textual Grounding, Task 2: Mask Comprehension, and Task 3: Auxiliary Mask Comprehension. Dynamic sampling is applied to stabilize the training of these tasks.

### 6. Detailed Module Design

**MDP Formulation:**
*   **State s ∈ S:** Represents the current segmentation result. Defined as a triplet s = (M, I,Q).
*   **Action a ∈ A:** Refers to the answer from the MLLM for SAM input. The initial action is the bounding box a = b. Subsequent actions are the points for mask refinement a ∈ {(p+, p−), (p+,null), (null, p−)}. When mask refinement is complete, the action is a = (null,null).
*   **Transition Function T : S × A → S:** Defines how the current state transitions to the next state given a specific action, i.e., s′ = T(s, a). Based on SAM, which generates a new segmentation mask M′ given the image I, current mask M, and current action a.
*   **Reward Function R : S × S × A → R:** Comprehensively considering the quality of current/next state and the action, providing the reward for the current transition, i.e., r = R(s′, s, a).
*   **Objective:** Maximize the expected reward E_{a∼πθ(a|s)}[R(s′, s, a)].

**Task 1: Textual Grounding**
*   **Mechanism:** The MLLM receives a grounding-specific prompt QB to generate the reasoning process and bounding box coordinates b.
*   **Rewards:**
    *   Box Reward: Combination of box IoU reward RB_IoU and box L1 reward RB_L1.
    *   SAM Reward RSAM: RSAM = IoU(M,MGT), where M = SAM(I, b).
    *   Formatting Reward: Enforces compliance with the required output format.

**Task 2: Mask Comprehension**
*   **Mechanism:** The MLLM is provided with an image overlaid by a green transparent mask M, predicted by SAM, together with Q. Prompted with QP, it predicts p+ and/or p−. SAM outputs an improved mask M′ = SAM(I,M, p+, p−).
*   **Data Collection:** Extract GT bounding boxes, provide to SAM. Masks categorized as Need Refinement if their IoU < 0.9, and Good Enough if their IoU = 1 (using modified IoU excluding near-edge pixels).
*   **Rewards:**
    *   SAM Reward RSAM = IoU(M′,MGT).
    *   Formatting Reward.
    *   Decision Reward RDCS_C: Score 1 if it produces refinement points when the mask is in Need Refinement, or terminates when Good Enough. 0 otherwise.
    *   IoU Imp. Reward R∆: Based on ∆ = IoU(M′,MGT)−IoU(M,MGT).
    *   Reward Combinations: For Need Refinement & (p+, p−) -> 0; For Need Refinement & others -> RENC; For Good Enough & (null,null) -> RDCS + 3; For Good Enough & others -> RDCS + R∆.

**Task 3: Auxiliary Mask Comprehension**
*   **Mechanism:** GT masks are intentionally corrupted with artificial imperfections (random polygonal inclusions for false positives, exclusions for false negatives). The MLLM is provided with the image overlaid with the imperfect mask M and Q. Prompted with QP to predict p+ and p− corresponding to the centers of the false negative and false positive regions.
*   **Rewards:**
    *   Decision Reward RDCS_A: Score 1 for outputting p− if a false positive region exists, or null if not. Analogous for p+ and false negatives.
    *   Point Reward: Score 1 if p− falls within a false positive region, and additional score 1 if distance from center < τd = 50 pixels. Analogous for p+.

**Dynamic Sampling Strategy**
*   **For Grounding Task:** Over-sample candidate boxes and apply Non-Maximum Suppression (NMS) to remove duplicates, increasing the diversity of rewards.
*   **For Mask Comprehension Tasks:** Over-sample actions until all four cases: (null,null), (p+,null), (null, p−), and (p+, p−) are represented. Encourages the MLLM to recognize differences among possible actions.

### 7. All Mathematical Formulas and Symbol Definitions

*   **MDP Tuple:** (S,A, T,R)
*   **State:** s = (M, I,Q)
*   **Initial Action:** a = b
*   **Refinement Actions:** a ∈ {(p+, p−), (p+,null), (null, p−)}
*   **Termination Action:** a = (null,null)
*   **Transition:** s′ = T(s, a)
*   **Reward:** r = R(s′, s, a)
*   **Objective:** E_{a∼πθ(a|s)}[R(s′, s, a)]
*   **Box Reward RB_IoU:**
    RB_IoU = {1, if IoU(b, bGT) > 0.5; 0, otherwise}
*   **Box Reward RB_L1:**
    RB_L1 = {1, if ∑_i |b_i − bGT_i| / 4 < 10; 0, otherwise}
*   **SAM Reward:** RSAM = IoU(M,MGT)
*   **IoU Change:** ∆ = IoU(M′,MGT)−IoU(M,MGT)
*   **IoU Imp. Reward R∆:**
    R∆ = 0, if ∆ ∈ (-1, 0]
    R∆ = 1, if ∆ ∈ (0, 0.1]
    R∆ = 2, if ∆ ∈ (0.1, 0.5]
    R∆ = 3, if ∆ ∈ (0.5, 1]
*   **Hard IoU Imp. Reward:** R∆_h = 3 · 1_{∆>0}
*   **Encouraging Score:** RENC = 2
*   **Point Reward Distance Threshold:** τd = 50

### 8. Algorithm Pseudocode

**Algorithm 1: Dynamic Sampling for Box**
Input: Actor model M , image I , text prompt P , number of rollouts R, maximum attempts A, maximum error count E, IoU threshold τ
Output: Valid rollouts R
R ← ∅, B ← ∅, ne← 0;
for a← 1 to A− 1 do
  C ←M(I, P ), B′ ← B;
  np ← |B|, ridx ← {−1}|B| i=1;
  foreach rollout r with index j in C do
    if |R| = R: returnR;
    if ¬ correctFormat(r) and ne < E :
      R ← R∪ {r}, ne ← ne +1;
      continue;
    B′ ← B′ ∪ {getBox(r)};
    ridx ← ridx ∪ {j};
  foreach k ∈ NMS(B′, τ)[: R] do
    if k ≥ np and |B| < R :
      B ← B ∪ {B′[k]};
      R ← R∪ {C[ridx[k]]};
if R− |R| > 0 :
  C ←M(I, P ),R ← R∪ C[: (R− |R|)];
returnR;

**Algorithm 2: Dynamic Sampling for Point**
Input: Actor model M , image I , text prompt P , number of rollouts R, maximum attempts A
Output: Valid rollouts R
R ← ∅;
ne ← 0;
cases← {error : 2, terminate : 1, positive : 2, negative : 2, both : 1};
for a← 1 to A− 1 do
  C ←M(I, P ) ;
  foreach rollout r ∈ C do
    if |R| = R :
      returnR;
    c← getCase(r);
    if cases[c] > 0 :
      R ← R∪ {r};
      cases[c]← cases[c] −1;
if R− |R| > 0 :
  C ←M(I, P );
  R ← R∪ C[: (R− |R|)];
returnR;
