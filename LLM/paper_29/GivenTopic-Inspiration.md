Given Topic: The research addresses memory mechanisms for large language model agents intended to progressively refine problem-solving competence through environmental interaction. Dominant paradigms suffer from critical constraints: parametric approaches internalize experience by modifying model weights, which inevitably induces catastrophic forgetting and erodes general knowledge. Retrieval-based approaches externalize experiences into structured databases, yet their effectiveness is fundamentally tethered to rigid context engineering and coarse, static appending of retrieved content, precluding seamless integration with ongoing reasoning. Existing latent memory methods remain largely confined to long-context compensation or continue to rely on invasive parameter updates and similarity-based fetching, lacking dynamic reconstruction capabilities. The central scientific challenge is how to architect agent memory as a dynamic cognitive faculty that fluidly interweaves with reasoning via generative, reconstructive processes, enabling context-sensitive memory invocation and synthesis while preserving the foundation model's inherent general capabilities.

Given Inspiration:
1. Human cognitive interplay: Human reasoning and memory operate as a continuously interleaved process, wherein recollection and thought dynamically reshape one another rather than proceeding as isolated, sequential stages.
2. Metacognitive monitoring: Human cognition possesses an intrinsic faculty for monitoring internal mental states and selectively invoking memory retrieval at opportune moments during problem-solving.
3. Memory consolidation: Biological memory systems reconstruct past experiences through selective filtering and integration, producing consolidated representations rather than verbatim restatement of prior content.
4. Cognitive identity: Past experiences fundamentally constitute cognitive identity, suggesting that agent behavior should be progressively shaped by fluid, experience-driven influences rather than static parameter updates or external database queries.
5. Deficiency of dichotomous storage: The rigid separation between internal parameter modification and external database retrieval fails to capture the naturalistic fluidity characteristic of biological memory systems.
